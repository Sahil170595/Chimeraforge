This is the aggregate-only **unreleased 0.89.0 source** record. Public installation
remains 0.86.0. `functional.json` is the immutable A development aggregate;
`functional-b.json` retains the B aggregate; `functional-c.json` qualifies the
corrected current source. These are generated by the real native adapter/CLI
consumer against owned local protocol fixtures; they are not an inference, GPU,
model-quality, human-truth or performance measurement. Native field names and
fixed tagged interface references are documented in [the feature guide](../../docs/chat-trace-replay.md).

The producer holds its complete declared source hash set before execution and
verifies it afterward. Hashes identify the recording host's actual RAW files;
Git-LF/wheel representations must be compared explicitly rather than assumed
identical. The producer checks known/unknown usage, distinct wire histories and
temperatures, native plan save/load, original fleet routing, private diagnostics,
late invalid input before contact and actual child/server closure. It uses the
existing planner and strict receivers; it does not fabricate an optimizer plan.

To regenerate in an existing development environment, use a **new** output:

```bash
python scripts/ci_chat_trace.py --record ./chat-trace-functional.local.json
```
